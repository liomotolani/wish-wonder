# Mockups

Static PNG exports of the Wish & Wonder design, at 2x resolution. Phone screens are 390 x 844; laptop screens are 1440 wide.

- `phone-NN-*.png` and `laptop-NN-*.png` with the same number are the same screen.
- `*-state-*.png` files are states of the screen with that number (empty, pending, Taken and so on). They exist for phone only.

The live, clickable canvas is the source of truth if an image and the canvas ever differ:
https://claude.ai/artifact/Mq9UfdKfAUubej9XeohWWk
